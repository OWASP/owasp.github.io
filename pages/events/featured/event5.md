## LASCON 2026!

(Training dates: October 27-28, 2026 / Conference dates: October 29-30, 2026)

The Lonestar Application Security Conference (LASCON) is an OWASP-associated annual conference held in Austin, TX. It is a gathering of 400+ web app developers, security engineers, mobile developers, and information security professionals. LASCON is held in Texas, where more Fortune 500 companies call home than any other state and is held in Austin, which is a hub for startups in the state of Texas. At LASCON, leaders at these companies along with security architects and developers, gather to share cutting-edge ideas, initiatives, and technology advancements.
